## Music Recommendation System

The hybrid music recommendation project is kept in its own directory so the original lab notebooks remain unchanged.

- [Project application and setup guide](music-recommendation/README.md)
- [Research, repository review, algorithms and implementation proposal](docs/MUSIC_RECOMMENDATION_PROJECT.md)
- [Model card and limitations](docs/MODEL_CARD.md)
- [Dataset notes and usage guidance](docs/DATASET.md)

The project includes a local web player, FastAPI backend, SQLite persistence, content-based filtering, SVD collaborative filtering, item-item KNN, popularity baseline, hybrid ranking, tests and offline evaluation.

The bundled tracks and listening events are synthetic demonstration fixtures. They are not real-world recommendation evidence.
